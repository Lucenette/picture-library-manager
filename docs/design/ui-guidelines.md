# 界面规范

**状态**：现行架构
**最后更新**：2026-10-19

**关联**：[theme.md](./theme.md)（颜色的唯一来源与主题切换）、[icon-library.md](./icon-library.md)（图标语义名）、[window-management.md](./window-management.md)（窗口骨架与自绘标题栏）

---

## 1. 背景

1. 界面此前没有成文规范：同一语义有多种取值——行高与控件高度散着 32 / 34 / 36 / 40 四种，过渡时长有 0.15s / 0.18s / 0.2s 三种，字号、圆角、阴影也直接写在组件里（实测见 §9）。
2. 参考了一批成熟产品的设计语言（Linear、Raycast 等公开的设计说明），要吸收的是**规则**不是皮肤：一个强调色、表面阶梯表达层级、发丝边代替阴影、信息密度优先、交互状态齐全。
3. 本项目的界面是**桌面工具**：鼠标精确操作、信息密度高、窗口尺寸由用户控制；营销站点那套大留白、大字号的节奏不适用。
4. 颜色已经有唯一来源（`src/common/theme/`），但尺寸、状态与组件规则没有落点——这份文档补上这一层。

## 2. 适用面

**管**：渲染进程的布局、间距、字号、圆角、控件尺寸、交互状态、动效；Element Plus 的覆写；主窗口、查看器、浮窗、弹窗四个入口。

**不管**：Monaco 编辑器内部（见 [monaco-textmate.md](./monaco-textmate.md)）、原生窗口与系统按钮（见 [window-management.md](./window-management.md)）、颜色值本身（见 [theme.md](./theme.md)）。

## 3. 五条原则

1. **一个强调色。** 主色只出现在：主操作、当前选中、焦点、链接。其余层级靠灰度与表面，不靠第二种彩色。
2. **表面阶梯表达层级。** page → surface → header 三级就够；密集界面不加投影，浮层才用阴影。
3. **信息密度优先。** 行高 32、控件 32 / 36、页面留白 16；用对齐和分组建立秩序，不用大留白撑气派。
4. **状态必须齐全。** 可交互元素一律有 hover / active / focus-visible / disabled 四态；缺一个就是半成品，不准只画默认态。
5. **令牌优先。** 颜色、间距、圆角、字号、图标尺寸、控件高度、动效时长只能取令牌；新值先进令牌表，再在组件里引用。

## 4. 令牌

### 4.1 颜色角色

| 角色 | 令牌 | 用法 |
|---|---|---|
| 页面底 | `--app-bg-page` | 主内容区底色；窗口外框色 |
| 表面 | `--app-bg-surface` | 卡片、表格、输入框、浮层的底 |
| 工具窗口 | `--app-bg-tool-window` | 脚本页的列表与编辑区（与编辑器底色相等） |
| 头部/栏 | `--app-bg-header` | 标题栏、导航栏、表头、状态栏 |
| 悬停 | `--app-bg-hover` | 行、按钮、图标的 hover 覆盖层（半透明） |
| 选中 | `--app-bg-active` | 当前项、下拉选中项、拖放目标 |
| 强选中 | `--app-bg-selected` | 平铺视图里真正选中的卡片 |
| 轨道 | `--app-bg-track` | 进度条底、滑块轨道 |
| 禁用底 | `--app-bg-disabled` | 禁用控件与禁用行 |
| 边框 | `--app-border` | 常规 1px 分隔与控件边框 |
| 弱边框 | `--app-border-subtle` | 表格行线、内部分隔 |
| 强边框 | `--app-border-strong` | 输入框、需要强调的边界 |
| 悬停边框 | `--app-border-hover` | 控件 hover 时的边界 |
| 高亮边框 | `--app-border-highlight` | 焦点、拖放目标描边 |
| 正文 | `--app-text-regular` | 默认文字 |
| 强调文字 | `--app-text-primary` | 标题、当前项、关键数字 |
| 次要 | `--app-text-secondary` | 说明、表头、状态栏 |
| 弱化 | `--app-text-muted` | 时间、计数、占位说明 |
| 禁用文字 | `--app-text-disabled` | 禁用态；不参与 hover |
| 主色 | `--app-primary` / `--app-primary-hover` / `--app-on-primary` | 主操作、选中、焦点、链接 |
| 语义 | `--app-success` / `--app-warning` / `--app-danger` / `--app-info` | 状态；**不做装饰** |
| 标签 | `--app-tag-{语义}-bg/-border/-text` | 三件套一起用，不单独取一个 |

规则：暗色下 surface 比 page 亮一档、浅色下同样（surface 更白）；**不要**用主色当卡片底或分区底；语义色只表达状态。

### 4.2 尺寸

| 类别 | 令牌 | 取值 | 用法 |
|---|---|---|---|
| 间距 | `--app-space-{2,4,6,8,10,12,16,20,24,32}` | 2..32 | 4 的倍数优先；6 / 10 只用于图标与控件内微调 |
| 圆角 | `--app-radius-{2,4,6,8}` | 2/4/6/8 | 2 角标、4 控件、6 面板、8 对话框与卡片；不准出现 9 这类临时值 |
| 字号 | `--app-font-{xs,sm,base,md,lg}` | 11/12/13/14/16 | 11 角标、12 辅助、13 正文、14 控件、16 小标题 |
| 行高 | 见 §4.3 | 正文 1.5 / 控件 1.2 / 标题 1.3 | 数字列用 `tabular-nums` |
| 图标 | `--app-icon-sm` 14、`--app-icon` 16、`--app-icon-lg` 18、`--app-icon-xl` 24 | 内联 / 常规 / 导航 / 占位字形 |
| 控件 | `--app-control-h` 32、`--app-control-h-sm` 28 | 按钮与输入 32、紧凑 28；Element Plus 的默认尺寸也挂这两个 |
| 弹窗标题条 | `--app-dialog-title-h` 36 | 弹窗类窗口自绘的标题条；主窗口 40 见 `--title-bar-height` |
| 行 | 32（列表与表格批次统一时再加 `--app-row-h`） | 表格行、列表项、树的行 |
| 动效 | `--app-duration-fast` 120ms、`--app-duration` 160ms、`--app-duration-slow` 200ms、`--app-ease` | 颜色 120、位移 160、展开收起 200 |
| 阴影 | 对话框 / 浮层 / 平铺卡片 / 查看器缩略图 | 见主题对象 | 密集界面不加投影 |

> 控件高度、图标、弹窗标题条与动效令牌已经落进两套主题；行高与剩余的间距字面量随列表 / 表格批次清。

### 4.3 文字层级

| 用途 | 字号 | 字重 | 行高 |
|---|---|---|---|
| 页面/区块标题 | 16 | 600 | 1.3 |
| 正文、表格单元格 | 13 | 400 | 1.5 |
| 表头、强调 | 13 | 600 | 1.3 |
| 控件文字（按钮、输入、下拉） | 14 | 500 | 1.2 |
| 辅助说明、状态栏 | 12 | 400 | 1.4 |
| 角标、计数 | 11 | 500 | 1.2 |

- 中文不加负字距；只有数字与英文标识可以 `tabular-nums`。
- 链接文字用主色，不加下划线；hover 时加下划线。
- 不使用斜体表达强调（代码区除外）。

## 5. 布局

**窗口骨架**：标题栏 40（拖拽区）+ 左侧导航 40（图标竖排）+ 主内容区；只有主内容区滚动。

**三种页面原型**：

1. **数据页**（来源、角色、图组、图库、任务）：`padding: var(--page-padding)`（16 16 0）；顶部工具栏不单设高度（按钮 32），与表格间距 12；表格占满剩余高度；分页固定在底部，`padding: 12 0 16`。
2. **工具页**（脚本）：满幅分栏，左栏 300、编辑区自绘底色；页面本身不留 `--page-padding`。
3. **设置页**：单列，内容最大宽 720，分组间距 24，分组内行距 8；页脚不放操作按钮，改动即时生效。

空状态：居中、最多一行 12 号次要文字；不放大插画，不放按钮（按钮放工具栏）。

## 6. 组件规则

- **按钮**：主操作（primary）一屏最多一个；次要与图标按钮用 default / text。高度 32（表格内 28），圆角 4，水平内边距 12。禁用降到底色与禁用文字，不响应 hover。
- **输入 / 选择**：高度 32，圆角 4，1px 边框；focus 用 2px 主色内描边，失焦回 1px；disabled 用 `--app-bg-disabled`；placeholder 用 `--app-text-muted`。
- **下拉 / 浮层**：surface 底 + 1px 边框 + `--app-shadow-popup`；选中项用 `--app-bg-active` + 强调文字，不用主色文字。
- **表格**：表头 `--app-bg-header`、13/600；行高 32；行线用 `--app-border-subtle`；hover 用 `--app-bg-hover`；不斑马纹；空表用空状态规则。
- **标签**：高 20、圆角 4、11 号 500；语义标签三件套一起用；同一行最多两个标签。
- **分页**：高 32，当前页主色实心，其余 surface + 边框。
- **对话框**：圆角 8，标题 16/600，内容内边距 24，底部按钮右对齐、间距 10；危险操作用 danger。
- **工具栏**：高 36，左右分布，元素间距 12；筛选项与按钮同高。
- **列表 / 树**：行高 32，组头与行同高；缩进用 12 的倍数；选中用 `--app-bg-active`，hover 用 `--app-bg-hover`。
- **拖放**：目标用 `--app-bg-active` + `--app-border-highlight` 内描边；拖动中的源不做位移，只降透明度。

## 7. 状态与可达性

| 元素 | hover | active / 选中 | focus-visible | disabled |
|---|---|---|---|---|
| 主按钮 | 主色 hover | 按下 0.97 缩放 | 2px 高亮边框 | 禁用底 + 禁用文字 |
| 次按钮 | `bg-hover` | `bg-active` | 同上 | 同上 |
| 输入 / 选择 | 边框转 strong | — | 2px 主色内描边 | 禁用底 |
| 表格行 | `bg-hover` | `bg-active` | 单元格获焦时 2px 内描边 | 禁用文字 |
| 列表项 / 树 | `bg-hover` | `bg-active` | 2px 高亮描边 | 禁用文字 |
| 链接 | 下划线 | — | 2px 高亮描边 | 禁用文字 |

- **所有键盘可达的元素都要有可见的 focus-visible 样式**；不许 `outline: none` 而不给替代。
- 焦点顺序与视觉顺序一致；浮层打开后焦点进浮层，Esc 关闭并还原。
- 颜色对比：正文 ≥ 4.5:1，次要文字与图标 ≥ 3:1（两套主题都要过）。

## 8. 明暗两套

- 暗色：层级靠**提亮**（page `#191a1c` → surface `#26282c`），阴影更重，hover 用白色 9% 覆盖。
- 浅色：层级同样靠 surface 更白（page `#f7f8f9` → surface `#ffffff`），边框更深，hover 用黑色 7% 覆盖。
- **同一个令牌在两套下角色相同**；组件只写令牌，不写条件分支。
- 新增令牌必须两套都给值（`test/scripts/stylesheet-tokens.test.ts` 守着键集合）。

## 9. 机械守卫

- **已有**：`stylesheet-tokens` 扫描——`src/renderer` 的样式里颜色只能用 `var(--app-*)` / `var(--el-*)`。
- **待加**（随第一批实施）：字号、圆角、过渡时长禁止字面量（扫描用例拦）；控件高度与行高改用令牌后同样禁止字面量。
- **只能人工**：两套主题 × 四个入口（主窗口、查看器、浮窗、弹窗）各看一遍；键盘 Tab 走一遍；对照本文件第 7 节的四态。

## 10. 改动时的检查点

- 新组件先取现有令牌；不够就**先加令牌**，不在组件里写字面量。
- 改 Element Plus 覆写先确认两套主题，再落 `styles/theme.css`；组件里不写 `:deep` 的全局覆写。
- 新增可交互元素时，把第 7 节表格里的四态逐条补齐。
- 改布局先认页面原型（数据页 / 工具页 / 设置页），不要新造第四种。
- 动效只动 color / background / border / opacity / transform；不动布局属性。

## 11. 已知取舍

| 取舍 | 代价 |
|---|---|
| 密度优先，行高 32、控件 32 | 触控板与高 DPI 下目标偏小；桌面鼠标场景可接受 |
| 密集界面不用投影 | 浮层与卡片靠边框区分，层级感弱于大阴影方案 |
| 一个强调色 | 复杂状态只能靠语义色与灰阶，不能靠彩色分区 |
| 参考对象是营销站点 | 只借规则（表面阶梯、发丝边、状态齐全），页面节奏与字号不照搬 |

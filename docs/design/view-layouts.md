# 平铺视图（图组管理 + 图库）

**状态**：现行架构
**最后更新**：2026-09-30

**关联**：[sort-keys.md](./sort-keys.md)（排序键与排序下推）、[ARCHITECTURE.md](../ARCHITECTURE.md)

---

## 1. 背景

1. **两个页面只有分页表格，看图挑选不趁手**：图组管理一屏几十行文字看不到图；图库虽有 90px 预览列，但整体按表格排，挑图要来回扫行。
2. **平铺不是「换个样式的表格」，而是相册式的两级结构**：一级看分组、点开看这个分组里的图。两页的「分组」含义不同——图组页是图组本身，图库页是**角色名**。
3. **图库页的封面现成，图组页没有**：前者每行都带 `selectedFileThumbnail`；后者要按组取代表图，而且必须是一条按分组的查询，不能逐行查。
4. **数据量可以很大，所以平铺不分页**：实测图库 4175 行、图组 4181 行、图片文件 25066 行；沿用分页会把相册切碎，改由懒加载 + 行窗口化支撑。
5. **原来的取数是「全量取回 + 内存分页」**：实测 4175 行查询 48ms、含 base64 约 77ms、缩略图字节 11.7MB（字符串约 15MB）；打开查看器还把整份列表连同缩略图塞进 IPC。重的那部分必须下推。

## 2. 范围

**做**

1. 图库页与图组页各有一个平铺视图，页脚左下角切换，偏好按页面记住。
2. 相册式两级：一级卡片（图库＝角色、图组页＝图组）＋行下展开的图片面板，一次只展开一个。
3. 两级都不分页：懒加载 + 行窗口化；筛选、排序、计数全部下推 SQL。
4. 与图片查看器接线：点图片打开查看器并定位到那一张，载荷只传来源与起始 id。

**不做**

- 平铺下「手动确认选图」没有入口（表格视图仍有「查看文件」）。
- 表格视图没有加载态：筛选与排序下推后有一瞬间空档。
- 卡片尺寸可调（缩略图大小）没做；窗口化已经按「尺寸可变」设计，只差设置项与入口。
- 键盘可达性与辅助技术适配。
- 视图偏好暂存 `localStorage`，等设置页落地再迁进 `settings.yml`。
- 两个筛选候选还不完整：图组页的「角色」只来自已加载的那一页，图库页的「处理脚本」不含已删除脚本留下的名字（手工输入仍能筛选）。

## 3. 两级结构与两页的分组含义

| 页面 | 一级＝分组 | 二级＝展开面板里的图片 |
|---|---|---|
| 图组管理（`ProcessPage`） | 图组 | 该图组的图片文件（含缩略图，分片取） |
| 图库（`LibraryPage`） | **角色名** | 该角色下的已选定图（含缩略图，分片取） |

- **图库按角色名归组**：`character` 表按来源唯一，同一个角色可能出现在多个来源里，那是同一张卡；卡片句柄取该名字下最小的 id，二级筛选也按名字走，卡片、三态与面板三处口径一致。
- 展开面板插在「该卡片所在那一行」的下方、占满整行；一级网格用它上方的卡片排版不变。

## 4. 点击与选中

| 动作 | 图组管理 | 图库 |
|---|---|---|
| 单击卡片封面 | 展开 / 收起该分组 | 同左 |
| 双击卡片 | 不做（第一次单击已经展开） | 同左 |
| 一级复选框 | 勾选该图组（批量处理 / 标记排除的单位＝图组） | **三态**：全选该角色下全部图片 / 部分选中 / 未选；勾选卡片＝选中它下面所有图片 |
| 二级图片 | 不提供勾选（图片级在图组页没有批量意义） | 单击＝打开查看器；勾选框按下面那条规则显示 |
| 打开整个分组 | 展开卡片后点面板里的图片（表格视图仍有「查看文件」） | 同左 |

- **复选框什么时候出现**：没有勾选任何一项时，只有鼠标悬停的那张卡片（或面板里那张图）显示复选框；一旦有任意一项被勾选（内层与外层都算），所有复选框常显。
- **放大、手型光标与点击都只认图片**：落到标题、名字或盒子上不触发。
- **选中是持久的**：翻页、改筛选、改排序、切视图都不清空，批量按钮始终看 `selectedIds`；表格用 `reserve-selection` 保住跨页勾选。
- **表格跨页选中只影响显示**：不在当前页的已选行不会画出勾选框，但仍在 `selectedIds` 里，批量操作包含它们。

## 5. 窗口化与自适应网格

- **两级共用同一套窗口化实现**：面板里嵌的是同一个列表组件（用 `mode` 区分一级/二级），二级因此也只挂视口附近的行。
- **行窗口化**：把卡片按当前列数切成一行行的数组，只把视口附近的那几行挂到 DOM 上，上下用 spacer 撑出总高度。
- **列数不写死**：卡片边长与横竖间距只在 CSS 变量里写一份（`--tile-card-size` / `--tile-gap-x` / `--tile-gap-y`），列数由它和栅格的实际可用宽度算出来；将来做「缩略图大小」设置只改这些变量。
- **行高与面板高度都是实测的**：行距取相邻两行顶边的距离（带面板的那一行跳过），面板高度取「面板自身高度 + 它与卡片之间的间距」；`ResizeObserver` 同时盯容器与卡片，改样式、改尺寸都会重新量。
- **展开面板的高度要计进 spacer**：面板滑出渲染窗口后它不在 DOM 里，spacer 得按实测高度把位置补平，否则总高度突然变矮、浏览器把滚动条往回夹；换分组或收起时，若旧面板在视口上方，再按它消失的高度补一次滚动位置。
- **内容坐标换算行号时要先减掉面板高度**：不减的话上方面板会把它下面的行整体推下去，算出来的行号偏大，最上面几行被提前卸载（表现为视口顶部露白）。
- 请求去重 + 过期响应丢弃：快速滚动与快速展开时会并发，响应回来只认最后一次。

## 6. 封面

- 尺寸与一级卡片一致（默认 100×100），`object-fit: cover`；没有缩略图用占位图标。
- **每个分组最多取三张叠着放**：第 0 张在最上面，另两张往两侧错开并稍作旋转；悬停时三张一起放大并加阴影，观感与查看器底部小图一致。
- **展开的蓝框画在最上面那张封面上**，跟着图片一起缩放旋转。
- 两级都只用一条按分组取代表图的查询（只查当前可见卡片的 id，每个分组最多回三行），不逐卡查。
- **角色封面按角色名取**：只按某个 `character.id` 取会让跨来源的角色只剩一张封面。

## 7. 视图切换与偏好

- 位置：页脚那一行的左下角（分页器占右下），一个图标按钮，点一下切换；平铺视图下隐藏分页器（它不分页）。
- 切视图回到第一页 / 顶部，筛选与排序保持。
- 偏好存 `localStorage`：`view-mode:process` / `view-mode:library`；读不到或值不认识就退回列表。

## 8. 与图片查看器的接线

- 图组页点二级图片 → 查看器打开**该图组**的图片并定位到这一张；图库页 → 打开**当前筛选结果**并定位到这一张。
- **载荷只传「来源 + 起始 id」**：图库给筛选条件与排序，图组页给图组 id；查看器自己一次取 120 张（以起始那张为中心），快到最后一张时续取下一段。
- 起始那张的下标用 `(排序键, id)` 的行值比较一次算出，降序跟着翻。
- 图组页平铺下不再提供「查看文件」（表格视图保留）；由此产生的「手动确认选图」缺口记在 §2。

## 9. 筛选与排序

- 语义与表格一致：图组页筛选作用于图组，图库页作用于单个图片（展示仍按角色分组，**筛选后为空的分组隐藏**）；**筛选条件一变就回到第一页**；输入加约 200ms 防抖。
- 排序全部下推 SQL：列名走白名单（`c.name_sort` / `f.file_name_sort` / `pi.script_name_sort` / `pi.confirmed_at`），客户端只给键、不给列名；文件名子串筛选里的 `%` 与 `_` 要转义。
- 排序键本身（规则、可插拔模块、列与索引）见 [sort-keys.md](./sort-keys.md)。

## 10. 取数：一律分片

- **重数据与一级索引行都分片**：统一 `LIMIT/OFFSET`（表格跳页与平铺加载更多共用同一套参数）+ **快照边界**（首次查询取一次 `MAX(id)`，之后所有分片都带 `id <= bound`，后台任务写入时不会重复或漏项）。
- 计数各一条 `COUNT(*)`（表格页码与「共 N 张」），筛选条件参与计数，页码与分片才对得上。
- 封面按当前可见卡片一条 SQL 拿完；图库的三态与整卡勾选靠一份**不带缩略图的轻量索引行**（只要 id 与角色名）在渲染进程内存里判断。

## 11. 代码组织

- 渲染进程三个文件：视图偏好（`useViewMode`）、切换按钮（`ViewSwitchButton.vue`）、平铺列表容器（`TileBoard.vue` 与其类型文件）；两级共用同一个容器。
- 两个页面只提供各自的数据与插槽内容；表格分支保留，只换数据来源。
- 排序键与它的升级、重建属于数据库模块，见 [sort-keys.md](./sort-keys.md)。

## 12. 改动时的检查点

- 改卡片尺寸或间距 → 只改 CSS 变量（`--tile-card-size` / `--tile-gap-x` / `--tile-gap-y` / `--tile-panel-max-height`）；列数与行距都是实测的，脚本不用动。
- 让卡片变高（多行标题、加副标题元素等）→ 行窗口化假设「除面板那一行外每行等高」，先确认这条还成立；不成立就要改成逐行实测 + 行高前缀和。
- 改面板的高度上限、标题栏或内边距 → 面板高度是实测的，但要确认「面板行滑出渲染窗口时总高度不变」，否则滚动条会被往回夹。
- 面板的高度上限必须交给 `el-scrollbar` 的 `max-height`（作用在滚动视口上）：只限最外层根节点的话，内容被裁掉而视口不溢出，内层直接滚不动。
- 二级的点击、悬停与手型光标都挂在图片上，不要挂回整个盒子。
- 换筛选 / 换视图必须回第一页、回顶部；筛选输入要保留防抖。
- 一级卡片按**角色名**归组，改回按 `character.id` 会让跨来源的同名角色裂成多张卡。

## 13. 已知取舍

| 取舍 | 代价 |
|---|---|
| 平铺不分页 | 靠懒加载 + 行窗口化；行高与面板高度是实测与估算混用，面板打开时滚动条的绝对位置略有偏差 |
| 两级共用同一个列表容器 | 面板里是嵌套的滚动容器，鼠标在面板上滚到底会链式带动外层 |
| 图库一级按角色名合并 | 不同来源的同名角色并成一张卡，卡片里混着几个来源的图片 |
| 表格跨页选中不画出勾选框 | 不在当前页的已选行仍在 `selectedIds` 里，批量操作包含它们，界面上看不出来 |
| 视图偏好存 `localStorage` | 换设备或清缓存就丢；要等设置页才能长期保存 |
| 筛选下推后表格没有加载态 | 改筛选或排序时有一瞬间空档，见 §2 |

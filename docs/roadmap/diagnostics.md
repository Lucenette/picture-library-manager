# 诊断：打开日志目录与收集日志

**状态**：待评审（由日志系统评审拆出，先登记需求）
**关联**：[logging.md](./logging.md)（日志系统本身）

---

## 1. 背景

1. 日志系统落地后，文件固定落在 `~/.plmanager/logs/`，但使用者要知道「去哪找」并不直观：Windows 上 `C:\Users\<用户名>\.plmanager` 默认是隐藏的。
2. 报问题时要能一次把材料给全：日志、应用版本、系统信息、以及必要的配置状态，而不是来回追问。

## 2. 目标与非目标

**目标**

1. **打开日志目录**：界面上一处入口，直接打开 `~/.plmanager/logs/`（`shell.openPath`）。
2. **收集日志**：把最近的日志与应用/系统信息打包，经另存为对话框导出成一个文件，供使用者发给维护者。

**非目标**

- 不做界面内的日志阅读器；不做自动上传。

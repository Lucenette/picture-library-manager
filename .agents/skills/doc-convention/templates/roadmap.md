[task-eta.md](../../../../docs/roadmap/task-eta.md)，带「目标与非目标」的较短形态是
[logging.md](../../../../docs/roadmap/logging.md)。

## 规则

- `**状态**` 只能取 [roadmap/README.md](../../../../docs/roadmap/README.md) 状态取值表里的五个值。
- 章节编号从 1 连续排到末尾，不跳号；子章节用 `### N.M`。章节数按内容增减（task-eta.md 用到 13 节）。
- 不需要的章节整节删掉，不要留空壳；「待决事项」没有就写「无」。
- 写完把文件登记进 roadmap README 的「事项」表，状态与文件内保持一致。
